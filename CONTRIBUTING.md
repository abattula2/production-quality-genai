# Contributing to Production-Quality GenAI

Thank you for your interest in contributing! Here are some guidelines.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

## Guidelines

- Add docstrings to all functions
- Include type hints in your code
- Write tests for new functionality
- Follow PEP 8 style guide
- Update README if necessary

## Areas to Contribute

- Additional notebooks and examples
- Improved documentation
- New use cases and applications
- Performance optimizations
- Test coverage improvements
- Bug fixes and issue resolutions

## Code Quality

Run these commands before committing:

```bash
black .
flake8 .
pylint **/*.py
pytest
```

## Reporting Issues

Before submitting a new issue, please:

1. Check if the issue already exists
2. Include detailed description of the problem
3. Provide steps to reproduce
4. Include your environment details (Python version, OS, etc.)

## Pull Request Process

1. Update documentation with any new features
2. Add tests for your changes
3. Ensure all tests pass
4. Link any relevant issues in the PR description
5. Be responsive to feedback during review

## Code of Conduct

Please be respectful and constructive in all interactions.

Thank you for contributing!
